# Amazon Application Migration Service

> AWS Application Migration Service (MGN) is the primary migration service recommended for lift-and-shift migrations to AWS. It performs continuous block-level replication of source servers (physical, virtual, or cloud) and launches them as EC2 instances, letting organizations migrate applications without changes and with minimal downtime. ## APIs

- [Amazon Application Migration Service API](https://docs.aws.amazon.com/mgn/latest/APIReference/Welcome.html): REST/JSON API over source servers, replication configuration, launch configuration, jobs, applications, and waves.
